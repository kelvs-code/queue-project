Clinic Queue Desk

A walk-in clinic serves patients in the order they arrive. That rule, first in, first out, is a queue. Try the desk below, then see the C++ program that powers the same logic.

Now serving:nobody yet

The eight boxes are one array. front marks the patient called next, rear marks the last arrival. When rear reaches the end, it wraps to index 0, so freed seats are reused.
